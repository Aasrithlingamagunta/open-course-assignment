# React Helmet PoC

## 📌 Overview
This is a Proof of Concept (PoC) React application demonstrating the usage of **React Helmet Async** for dynamic title and meta tag management.

## 🛠 Tech Stack
- React.js
- React Helmet Async (`react-helmet-async`)

## 🚀 Features
- Updates the `<title>` dynamically using `React Helmet Async`
- Demonstrates how to use `HelmetProvider` efficiently
- Simple and clean implementation
